Wave Dash

Wave Dash is a one-button neon wave-riding game. Hold to glide up, release to dive down, and thread your wave through the gaps without crashing. Every obstacle passed is a point — every crash starts a new attempt.

Fly upHold Space / Click / Touch PauseEsc or P Scoring+1 per obstacle cleared ModesEasy / Medium / Hard • Normal / Mini wave

Engine: HTML5 Canvas 2D • Shell: Next.js 16 + Tailwind CSS • Icons: Lucide

Soundtrack: original synthwave tracks rendered in-house, royalty-free.

Version 3.0.0 • Progress saved locally on your device • Secure sign-in by Clerk
